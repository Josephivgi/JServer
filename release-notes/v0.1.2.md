**New**

- Memory now shows what programs use apart from what Linux keeps as cache. Server cards and the Memory tile have a two-part bar (solid for programs, light for cache), and the memory chart has Used and Cache lines. Proxmox and other ZFS servers no longer look nearly full because of the ZFS cache.
- When a server times out, cannot be reached or drops the connection, JServer tries again by itself after 30 seconds, then 1, 2, 5, 10 and every 15 minutes. Monitoring comes back after your PC sleeps or the Wi-Fi drops. The card shows when the next try is. A rejected key still waits for Retry.
- Hosts in included config files, such as `Include config.d/*`, now show up.

**Improved**

- Status dots are gone. Servers that are fine show plain text, and problems show a warning icon with the reason in color.
- Memory warnings go by what programs use, so a large cache no longer sets them off.
- Network Out, Disk Write and ZFS cache use their own color instead of the warning color.
- Resume monitoring only logs in to that server, not every server that failed.

**Fixed**

- A dropped connection sometimes showed the wrong reason, such as "cannot open /proc/...". Drops now show "Connection lost" or "Network error".
- The count of programs Linux stopped for lack of memory was wrong if the server restarted in that time.
- Saving `~/.ssh/config` at the wrong moment could make JServer forget every server and which ones were paused.
- Hovering cut-off text like a key fingerprint showed the same tooltip twice.
- The same disk mounted in two places showed twice.
